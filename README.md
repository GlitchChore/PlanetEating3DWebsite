# Planet Eating – Webseite

Diese Webseite ist die öffentliche Startseite des Unity-Spiels **Planet Eating**.

## Aktueller Stand

- Spielübersicht mit den wirklich vorhandenen Inhalten aus Zone 1 und Zone 2
- klarer Hinweis auf noch laufende Mehrspieler-Prüfungen und den fehlenden zweiten Boss
- vorbereitete Bereiche für Spielkonto und Windows-Download
- passende Darstellung auf Computer und Handy
- eigene Vorschau-Grafik für geteilte Links

Das Spielkonto kann auf der Webseite noch nicht geöffnet werden. Der Windows-Download ist ebenfalls noch nicht veröffentlicht. Beide Bereiche sind deshalb sichtbar als noch nicht verfügbar markiert.

## Lokal starten

Benötigt wird Node.js ab Version 22.13.0.

```bash
pnpm install
pnpm run dev
```

Die fertige Webseite wird mit `pnpm run build` geprüft.
